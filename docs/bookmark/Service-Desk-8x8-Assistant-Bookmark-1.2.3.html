Service Desk 8x8 Assistant · Prototype 1.2.3

Your assistant, one click away.

Add the favourite once. Click it whenever you open or refresh 8x8.

1. Add to your favourites bar

Open this downloaded file in Microsoft Edge. Press Ctrl + Shift + B to show the favourites bar.

Drag the button below onto the favourites bar.

8x8 Assistant

Drag this button to install it. Use the saved favourite from your 8x8 tab.

Prefer to import it?

In Edge Settings, find Import browser data. Choose Favorites or bookmarks HTML file, then select this same downloaded file.

Find 8x8 Assistant in the imported favourites and move it onto your favourites bar.

2. Start the assistant

  1. Open your signed-in vcc-au2.8x8.com tab and let the page load.
  2. Click your saved 8x8 Assistant favourite.
  3. Open queue information and keep your usual ITS group and status filters selected.

Refresh or reopen 8x8? Click the favourite again. Your existing Data location setting still restores Call Notes when access is allowed.

Author: Joshua Lavagna-Slater · Prototype 1.2.3

The favourite includes this version of the assistant. It downloads no code when clicked. Replace it when installing a newer prototype.

If your organisation blocks JavaScript favourites, keep using the approved launch method. This installer does not change browser policies or install an extension.
