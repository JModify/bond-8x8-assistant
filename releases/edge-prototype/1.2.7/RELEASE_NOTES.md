# Prototype v1.2.7

- Stop suggesting or automatically filling caller names for Student Assist Desk calls; enter each caller’s name or SID normally.
- Set the Student Assist Desk extension in Settings, defaulting to 55848. It controls the call label, note tags and name exemption.
- Add or remove full shared phone numbers under Exempt Name Suggestion in a compact scrolling list.
- When several names are saved for one number, choose Mark as shared number during the call to add it to exemptions. Ambiguous lines never auto-fill a caller name.
- Keep typed names, notes, existing call records and counters intact.
