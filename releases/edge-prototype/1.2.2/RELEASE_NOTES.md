# Prototype v1.2.2

- Browse large Call Notes histories in pages, with faster searching and file loading. Search and export still include every note.
- Support up to 10,000 records or 20 MB in one data file. See the technical guide for practical limits and archiving advice.
- Automatically retry a remembered data file after temporary access, connection or file-lock problems. Explicit Disconnect stops retries; Edge may still need permission.
- Base the phone-cover alert only on the caller's Longest waiting time, with the queue and actual waiting time shown in the alert.
- Keep monitoring working when you are the only signed-in agent and 8x8 replaces its empty Groups list.
